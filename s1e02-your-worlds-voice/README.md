# Dreamer's Voyage Workshop, episode 2: your world's voice

`workshop-episode-2.json` holds everything typed into the Workshop world in this episode: the Story Overview (world background
and quest generation guidance), the Narrator Style and two World Lore entries.

To try it: open your own test world in Voyage Studio, open each file (Story > Story Overview, Narrator Style, World Lore), switch
to the JSON view and paste the matching part in, or copy the text into the boxes. Save Draft. Use a test world, not one people play.
