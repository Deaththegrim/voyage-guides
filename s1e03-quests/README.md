# Dreamer's Voyage Workshop, episode 3: quests

`workshop-episode-3.json` is the quest from this episode, The Lion's Gone Walkabout, as Voyage stores it.

To try it: open a test world in Voyage Studio, go to Story > Quests, switch to the JSON view and paste the quest into the
`quests` object (or copy each field into the form). It starts hidden, so nothing hands it out until a story start or a trigger
does (episodes 10 and 20). Save Draft. Use a test world, not one people play.
