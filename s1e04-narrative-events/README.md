# Dreamer's Voyage Workshop: narrative events

`workshop-episode-narrative-events.json` is this episode's narrative event, gilt_circus_offer, plus the lion quest with the one
change that starts it (its onCompleteEffects carries a narrative-event-start naming the event).

To try it: open a test world in Voyage Studio. Paste the event into Story > Narrative Events (JSON view) under its key, and the
quest into Story > Quests. Save Draft. Use a test world, not one people play.
