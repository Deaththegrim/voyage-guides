# Dreamer's Voyage Workshop, episode 5: the map

`workshop-episode-5.json` is the Workshop world's map from this episode: one realm (The Trade Roads), two regions (The Hollow
Counties, known, and The Gloamwood, not known yet), the town of Mudbury with its four areas, and the lion quest now set in Mudbury.
The server stores "known" for what Voyage's docs call "initialKnown"; both are accepted.

To try it: open a test world in Voyage Studio and paste each part into Map > Realms, Regions and Locations (JSON view); areas
ride inside Mudbury. Save Draft. Use a test world, not one people play.
