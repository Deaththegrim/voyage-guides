# Dreamer's Voyage Workshop, episode 6: the map II

`workshop-episode-6.json` is the location archetype we wrote in this episode, Show Comes to Town: atmosphere, tensions, patterns
and secrets, three lines each, the same parts Voyage's own location archetypes use.

To try it: open a test world in Voyage Studio, go to Map > Advanced > Location Archetypes, switch to the JSON view and add the
entry beside the ones already there. Save Draft. Use a test world, not one people play.
