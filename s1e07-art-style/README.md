# Dreamer's Voyage Workshop, episode 7: art style

`workshop-episode-7.json` is the Workshop world's Image Prompts: one STYLE LOCK (Gravity Falls) in all five boxes, NPCs, Locations,
Areas, Regions and Items, with labelled sections (Person, Creature, Player Character, Default) in the NPCs box.

To try it: open a test world in Voyage Studio, go to AI > Image Prompts, switch to the JSON view and paste it in, or copy each box
into the form. Change the STYLE LOCK paragraph to the show your world should look like, then make one test portrait before you
generate anything else. Save Draft. Use a test world, not one people play.
