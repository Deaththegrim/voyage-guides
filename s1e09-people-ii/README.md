# Dreamer's Voyage Workshop, episode 8: people II

`workshop-episode-8.json` holds what this episode added: two NPC types (Road Bandit, Gloamwood Thing), both shows as factions
(Dreamer's Travelling Show and The Gilt Circus, each with a World Lore entry of the same name and text), one NPC archetype
(Show Folk) and one author seed (Road Show). In the episode, Dreamer and Old Marla belong to the show and Lucius Gilt to the Gilt
Circus; set that on each person's Faction. The server stores "known" for what Voyage's docs call "initialKnown"; both are accepted.

To try it: open a test world in Voyage Studio and paste each part into its page in JSON view: Characters > NPCs > NPC Settings >
NPC Types and Factions, Story > World Lore, and NPC Settings > Advanced for the archetype and the seed (add them beside the ones
Voyage ships). Save Draft. Use a test world, not one people play.
