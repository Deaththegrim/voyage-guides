# Dreamer's Voyage Workshop, episode 10: the player character

`workshop-episode-10.json` holds this episode's part of the Workshop world: two premade characters (Jack Tumble, Nell Bramwell, no
traits yet: traits come in season two), the show's random names (country-fair names with surnames), and our Elara entry for the name
filter (Voyage ships Elara; we changed its replacements to names that fit our towns).

To try it: open a test world in Voyage Studio, go to Characters > Player Character and paste each part into its page in JSON view
(Premade Characters, Random Character Names), and the Elara entry into Characters > Name Filter Settings. Save Draft. Use a test
world, not one people play.
