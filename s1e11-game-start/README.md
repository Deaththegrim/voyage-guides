# Dreamer's Voyage Workshop, episode 11: game start

`workshop-episode-11.json` holds this episode's story start (The Lion's Gone Walkabout, set as the default, opening at Mudbury's
Show's Camp with the lion quest handed out from turn one) and the two game modes (Opening Night, Off Night).

`workshop-world-season-1.json` is the whole Workshop world as season one leaves it: every part from episodes 2 to 11.

To try it: open a test world in Voyage Studio. For the whole world, go to Content, switch to the JSON view and paste the file in. For
this episode's parts alone, paste each into Game Start > Story Starts and Game Modes in JSON view (the start needs Mudbury from
episode 5 and the lion quest from episode 3). Save Draft. Use a test world, not one people play.
