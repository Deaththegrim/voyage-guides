# Dreamer's Voyage Workshop, episode 12: items

`workshop-episode-12.json` holds this episode's items (the mark, our currency; Throwing Knives; a Patched Ring Coat; a Bottle of
Liniment) and the Item Settings parts we changed: the currency name, a weapon slot added to Voyage's armour slots, and everyone's
starting items (5 marks and a liniment). Tiers stay as Voyage's new world sets them.

To try it: open a test world in Voyage Studio. Paste the items into Items > Premade Items in JSON view. In Items > Item Settings,
set the currency name, add the weapon slot and the starting items. Save Draft. Use a test world, not one people play.
