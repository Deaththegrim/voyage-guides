# Dreamer's Voyage Workshop, episode 14: abilities

`workshop-episode-14.json` holds the three moves from this episode: Fan Throw (needs dexterity 12), Slip the Cuffs (needs level 2)
and Crowd Pleaser (needs charisma 12). Each description says what the move does first, then how it looks.

To try it: open a test world in Voyage Studio, go to Mechanics > Abilities, switch to the JSON view and paste them in. The
requirements name Voyage's default attributes. Save Draft. Use a test world, not one people play.
