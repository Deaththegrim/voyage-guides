# Dreamer's Voyage Workshop, episode 15: skills

`workshop-episode-15.json` holds the three circus skills from this episode: knife throwing (combat, dexterity, comes with the Throwing Knives), sleight of hand (dexterity) and animal handling (wisdom). Knife throwing names the Throwing Knives item from episode 12, so paste that too or swap it.

To try it: open a test world in Voyage Studio, go to Mechanics > Skills, switch to the JSON view and paste it in. Save Draft. Use a test world, not one people play.
