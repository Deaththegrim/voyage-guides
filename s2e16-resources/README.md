# Dreamer's Voyage Workshop, episode 16: resources

`workshop-episode-16.json` holds the stamina bar from this episode: 50 to start, 5 more a level, 2 back each turn and all of it on a rest, with usage instructions in three parts (what spends it, the costs, when not to take any).

To try it: open a test world in Voyage Studio, go to Mechanics > Resources, switch to the JSON view and paste it in. Save Draft. Use a test world, not one people play.
