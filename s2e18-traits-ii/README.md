# Dreamer's Voyage Workshop, episode 18: traits II

`workshop-episode-18.json` holds Fire Eater, the act added in this episode: unlocked by Born on the Road, resists fire. Add it to a category's traits list too, or it won't show in the creator.

To try it: open a test world in Voyage Studio, go to Mechanics > Traits > Traits, switch to the JSON view and paste it in. Save Draft. Use a test world, not one people play.
