# Dreamer's Voyage Workshop, episode 20: the advanced mechanics

`workshop-episode-20.json` holds the show's milestone titles, the camp knockout for death, and the show's winning and losing endings.

To try it: open a test world in Voyage Studio, go to Mechanics > Advanced (Level Progression, Death Rules, End of Game Rules), switch to the JSON view and paste it in. Save Draft. Use a test world, not one people play.
