# Dreamer's Voyage Workshop, episode 21: triggers 101

`workshop-episode-21.json` holds this episode's two triggers: bramble_in_the_roses (fires once: a place check plus a story check) and running_on_empty (recurring, mechanical). They name our world's area, NPC and stamina bar, so rename those to yours.

To try it: open a test world in Voyage Studio, go to Mechanics > Advanced > Triggers, switch to the JSON view and paste it in. Save Draft. Use a test world, not one people play.
