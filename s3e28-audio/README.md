# Dreamer's Voyage Workshop, episode 28: audio

`workshop-episode-28.json` holds the voices from this episode: The Ringmaster, Gilt Whisper, and Road Drawl and Farm Girl for players in the creator. To hand one to a character, pick it in that character's World voice ID box.

To try it: open a test world in Voyage Studio, go to Audio > Voices, switch to the JSON view and paste it in. Save Draft. Use a test world, not one people play.
