# Dreamer's Voyage Workshop, episode 29: mods

`workshop-episode-29.json` holds a tiny example mod: two encounter palettes of Gilt Circus trouble on the road. Every key starts with Gilt Circus, so it can't land on top of an entry a world already has.

To try it: open a test world in Voyage Studio, go to AI > Encounter Elements (in a mod: Create a World, set Type to Mod), switch to the JSON view and paste it in. Save Draft. Use a test world, not one people play.
